{%- comment -%} Build-time coloring for a captured Gherkin box (sl-4l16, punch item P3). Rouge's gherkin lexer cannot lex a ShiftLefter step: its scenario-keyword rule is `(.*?)(:)`, so the colon in every subject (`:user/alice`) turns the rest of the step into one error token. This include classifies the words instead. The text stays the captured file word for word — splitting on a sentinel keeps the empty strings, so indentation and double spaces survive — and the token classes are Rouge's (k, kd, nt, ss, nc, nv, s, c1), so the one theme block in theme.css covers both. No scripts, CSS only.
