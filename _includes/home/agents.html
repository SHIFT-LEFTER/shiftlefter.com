For agents

If you're an agent, or you brought one: install, then ask the tool itself.

curl -fsSL https://raw.githubusercontent.com/SHIFT-LEFTER/shiftlefter/main/release/install.sh | bash
./sl/sl orient            # where am I, what would fail, what to read next
./sl/sl agent-doc --list

Hand it a suite it has never seen and it parses everything, runs nothing, and names the next command — the untouched Cucumber feature under Promise. The full agent surface is documented in the repository; the installer prints a breadcrumb stanza to paste into your AGENTS.md; a plain-text pointer lives at /llms.txt.

Rarity: rare.
